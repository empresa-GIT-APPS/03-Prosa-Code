# 🎨 UI/UX e Identidade Visual — Prosa Code

Bem-vindo ao diretório de **UI/UX e Identidade Visual** do projeto **Prosa Code**. Aqui está registrada toda a evolução do design da nossa marca, desde as ideias e rascunhos manuais até as artes finais em alta fidelidade.

---

## 📂 Estrutura do Diretório

Seguindo os padrões de organização de software, nossa documentação visual está dividida em duas etapas principais:

| Pasta | Descrição | Nível de Fidelidade |
| :--- | :--- | :---: |
| ✏️ **[`wireframes/`](wireframes/)** | Rascunhos no papel, desenhos conceituais e anotações iniciais. | Baixa Fidelidade |
| 🎨 **[`mockups/`](mockups/)** | Artes digitais finalizadas em *pixel art*, paleta de cores e banner oficial. | Alta Fidelidade |

---

## 💡 Resumo da Identidade Visual

- **Conceito Geral:** A marca foi idealizada para criar uma "vibe de biblioteca/sebo", unindo a paixão pela leitura ao café e ao desenvolvimento de software.
- **Símbolo Principal (A Xícara e o Café):** Representa simultaneamente o momento aconchegante da leitura e o ecossistema da linguagem **Java**.
- **Autoria da Logo e Banner:** Ideação, esboços e prompt visual desenvolvidos por **Rayssa**.
- **Paleta de Cores:** Definição dos tons terrosos e verdes feita colaborativamente por toda a **equipe**.
