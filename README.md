## 📝 Descrição

O **Prosa Code** é um sistema desktop de gestão de estoque e vendas desenvolvido especificamente para sebos e livrarias de segunda mão. O projeto une a estrutura do paradigma de Programação Orientada a Objetos (POO) a uma interface gráfica rica em estilo *pixel art*, inspirada na estética de bibliotecas botânicas e cafés.

A aplicação resolve os desafios de catalogação de acervos usados, precificação flexível, controle de fornecedores e registro de vendas, oferecendo uma experiência visual fluida e temática para os usuários.

---

## 🎯 Objetivos

* 📖 **Gestão do Acervo:** Registrar, atualizar, consultar e remover livros do acervo do sebo.
* 📦 **Controle de Estoque:** Monitorar exemplares disponíveis, categorias, estado de conservação e preços.
* 📇 **Agenda Integrada:** Manter um registro de contatos para fornecedores, clientes e parceiros.
* 🎨 **Interface Temática:** Proporcionar uma experiência gráfica imersiva em estilo pixel art botânico/café.
* 🧩 **Aplicação Prática de POO:** Implementar conceitos de encapsulamento, herança, polimorfismo, interfaces e persistência de dados via JDBC.
